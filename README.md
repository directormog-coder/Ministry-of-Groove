# Ministry of Groove (M.O.G.)

**THE MINISTRY OF GROOVE — THE CABINET (PTY) LTD — EST. 2026**

A high-performance secure web application and community hub for Amapiano music, built with **Next.js**, **Supabase**, and **Tailwind CSS**, deployed on **Vercel**.

---

## 🏛️ Platform Architecture & Features
* **Executive Command Hub**: Centralized navigation with luxury gold and cyan design standards.
* **Real-Time Communication**: Live chat integrated with Supabase database channels using the `useChat` hook.
* **Interactive Modules**: Includes Live Streams, Music Vault, Voting Cabinets, Event Ticketing, and Gallery archives.
* **Progressive Web App (PWA)**: Fully configured with custom manifests and high-resolution icons for native mobile installation.

## 🛠️ Tech Stack
* **Framework**: Next.js (Pages Router)
* **Database & Real-time**: Supabase (PostgreSQL)
* **Styling**: Tailwind CSS & Custom Globals
* **Hosting & CI/CD**: Vercel

## 🔒 Security & Compliance
